# Отчёт: сайт-портфолио «Под ключ»

**Сайт:** https://alexandrcherezau.github.io/
**Репозиторий:** https://github.com/AlexandrCherezau/AlexandrCherezau.github.io
**Figma (редактируемый макет, десктоп и телефон):** https://www.figma.com/design/HPI7TSdwRrxNFPDsyFidiU

## Что сделано
- Одностраничный сайт на Next.js 16 со статическим экспортом: hero с 3D-шаром из клавиш (R3F), услуги, 8 кейсов с фильтром и модальной галереей, «как идёт работа», 15 отзывов с Kwork, блок Kwork, FAQ, финальный CTA с висящим бейджем.
- Прелоадер: клавиши слетаются по реальному прогрессу загрузки GLB и атласа (`useProgress`), счётчик скрывается не позже 2,5 с, при повторном визите сборка пропускается (localStorage).
- 3D реагирует на курсор, наклон телефона (Android, где не нужен запрос разрешения) и скролл (шар раскрывается). Рендер останавливается, когда hero вне экрана или вкладка скрыта. DPR 1–1,75 (телефон до 1,5), на телефоне 40 клавиш вместо 56.
- Фолбэки: без WebGL, при программном рендеринге, ошибке загрузки или потере WebGL-контекста показывается постер (он есть в серверном HTML), есть кнопка «Повторить». Reduced motion: без Lenis, без вращения, контент виден сразу.
- Контент в `src/content/*.json`, SEO: метаданные, OG 1200×630, sitemap.xml, robots.txt, JSON-LD (Person + Service), фавиконки и manifest.
- Автодеплой: GitHub Actions на каждый пуш в `main` (typecheck, lint, build, публикация в Pages).

## Решения и обоснования
- **Дизайн-направление «клавиатурная мастерская».** Клавиша = «ключ», отсюда «под ключ». Палитра набора кейкапов: тёмная хвоя #0E1613, кремовые клавиши #EDE6D6, один акцент «Enter» #F5C542. Шрифты Unbounded + Onest (кириллица). Из референса взяты приёмы (прелоадер, превращающийся в героя; объект из клавиш; гигантский обрезанный вордмарк; смена фона секций; висящий бейдж), а не вид: цепи заменены витым кабелем, палитра и тексты свои. Разбор видео: `tmp/video-notes.md`.
- **Кейсы (8):** мини-CRM, салон с записью, парсер каталога (демо с кодом на GitHub), RepoOracle (open source, AI-бот), бот слежения за ценой (концепт), Brest Bus (реальный проект), кофейня и отель (демо). Покрыты все направления. Всё, что не реальный заказ, подписано на карточке. Инвентаризация: `tmp/projects.md`. Не взяты: Lampa Stream (сомнительный контент), ardar (секреты в каталоге), Lumora (нет скриншотов).
- **Цены и сроки** взяты из кворка, на который ведёт кнопка услуги (цены сверены с живым профилем 15.11.2026, сроки из `kwork-portfolio/src/niche/kworks.json`, по которому кворки создавались).
- **Контакты:** Telegram @cherevichk_a (ник аккаунта, к которому подключён Telegram-инструмент этой машины), Kwork AlexandrCherezau, GitHub AlexandrCherezau. Почту на сайт не ставил: в профиле Kwork и проектах публичной почты нет.
- **Имя и хостинг:** репозиторий `AlexandrCherezau.github.io` даёт корневой адрес без подпапки. Варианты коротких имён на других хостингах (`podkluch`, `pod-kluch`, `podklyuch`, `klyuch-dev`, `cherezau`, `alex-podkluch`): на 15.11.2026 все свободны на netlify.app, vercel.app и pages.dev. Лучшее: `podkluch`.

Повторного ревью после исправлений не было; исправления проверены сборкой, линтером и браузерными сценариями ниже.

## Проверки (на опубликованном сайте, headless Chromium через Playwright)
- `npm run typecheck`, `npm run lint`, `npm run build`: без ошибок (локально и в Actions).
- 390, 768, 1440 px: нет горизонтального скролла (scrollWidth = clientWidth), ошибок в консоли нет. Есть одно предупреждение `THREE.Clock deprecated` из самой библиотеки R3F, на работу не влияет.
- Прелоадер, 3D, фильтр кейсов, модалка (открытие, стрелки, Esc с возвратом фокуса), FAQ с клавиатуры, skip-link: работают.
- Без WebGL: постер, контент и кнопки на месте. Reduced motion: шар сразу собран, анимаций нет. Slow 4G + CPU ×4: контент и CTA видны сразу, 3D догружается.
- Ссылки: Telegram (все варианты с текстом), GitHub, репозитории кейсов, бот RepoOracle, Brest Bus отвечают 200. Ссылки на кворки скопированы с живого профиля, но открыть каждую повторно не удалось: Kwork после серии запросов включил антибот (403 и для curl, и для браузера). Стоит прокликать их самому.
- Lighthouse mobile (`artifacts/lighthouse/mobile-run1..3`): Performance 96 / 97 / 99, Accessibility 100, Best Practices 100, SEO 100, LCP 2,4 / 2,3 / 1,4 с, CLS 0 / 0 / 0,028, TBT 110–150 мс.
- Важно: Lighthouse работает без видеокарты, поэтому сайт показывает ему постер вместо 3D (так задумано для слабых устройств). С принудительным 3D (`?3d=force`, программный рендеринг) Performance 69 и TBT 8,9 с (`artifacts/lighthouse/mobile-3d-forced`). На устройствах с GPU сцена рисуется видеокартой, но на реальном телефоне я её не проверял.
- Скриншоты: `artifacts/screens/`.

## Что не удалось или не проверено
- Реальный телефон и реальная видеокарта не проверены (только headless Chromium с программным WebGL).
- Встроенная панель браузера была скрыта, поэтому визуальная проверка шла через Playwright.
- Открытие каждого кворка по ссылке (антибот Kwork, см. выше).
- iOS: наклон телефона не используется, потому что Safari требует отдельного разрешения.

## Что можно улучшить самому
- Купить домен (например, podkluch.ru) и привязать к GitHub Pages: Settings → Pages → Custom domain. Тогда поправить `siteUrl` в `src/content/site.json`, `robots.txt` и `sitemap.xml`.
- Добавлять новые отзывы в `src/content/reviews.json` дословно с Kwork и обновлять статистику там же.
- Снять настоящий скриншот чата RepoOracle и заменить обложку в `public/cases/repooracle-1.webp`.
- Если нужен короткий адрес без своего домена: подключить Netlify (имя podkluch свободно) через вход по GitHub.
